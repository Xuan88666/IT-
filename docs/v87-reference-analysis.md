## 产品整合原则

1. 按任务组织，不按协议名堆菜单：现场处置、桌面与办公、网络与设备、管理交付、知识与扩展。
2. 自研能力和开源集成分开：自研工具直接运行；Wireshark、Nmap、iperf3 等显示依赖状态、官方来源和启动入口。
3. 每个工具必须有真实输入、真实输出、结论、复制/导出和执行记录；没有真实数据源的功能不标记为完成。
4. 修改系统状态的动作必须先展示风险、要求确认、写入审计，并给出回滚路径。
5. 所有旧工具继续保留；新增能力优先合并到现有工作台，避免侧边栏无限膨胀。
