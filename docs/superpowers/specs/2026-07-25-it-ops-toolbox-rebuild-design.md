# IT 运维百宝箱重构设计

## 目标

将现有本地优先的运维工具集重构为面向 Windows 桌面运维和现场 IT 支持的工作台。项目名称统一为“IT 运维百宝箱”。

本次重构以完整保留既有工具和每个工具的输出台为前提；不删除工具 ID、现有执行入口或可用功能。新增能力必须使用同一套参数、运行、输出、结论、导出和审计体验。

## 已确认的产品原则

- 所有现有网络、系统、打印、监控、实用、远程和运维管理工具均需保留并可访问。
- 每个工具保留独立输出台；运行结果可复制、清空、导出、重试和关联处置记录。
- 桌面运维是第一优先级，Windows 为首期运行平台。
- 内置自研能力与外部开源工具分区展示；外部工具只做本机检测、说明和合法启动桥接。
- 修复类操作必须明确风险、权限、变更范围和回滚方式，默认先检测后执行。
- 知识库必须恢复品牌/设备/故障/官方资料的完整入口，并能服务现场排障与 AI 建议。

## 改造策略

采用增量重构，而非一次性重写。

1. 先建立工具注册、运行、输出和首页聚合的公共边界。
2. 将现有工具按原 ID 接入注册表，确保既有入口和处理函数继续工作。
3. 恢复知识库后端已有的内置 SOP、官方来源和导入能力，再扩展资料结构与前端检索。
4. 新增电脑优化与 Office/WPS 修复模块，接入同一运行框架。
5. 在不改变本地优先、RBAC、审计和已有 API 合同的前提下，逐步拆分过大的前端协调文件。

## 信息架构

### 一级导航

- 工作台：设备状态、快捷操作、最近运行、异常与待办。
- 桌面运维：电脑体检、电脑优化、Windows 修复、办公修复、软件管理、打印与外设。
- 网络与现场：现有网络诊断、网络服务、拓扑、监控与现场 SOP。
- 运维管理：资产、工单、处置单、知识库、监控告警、审计日志。
- 集成工具：已检测的开源/外部工具、安装状态、版本、说明与启动入口。
- 设置：账号权限、AI 提供商、数据备份、界面和本地服务设置。

所有原工具必须同时可以由分类、全局搜索和工作台快捷入口到达。

### 首页

首页不重复工具逻辑，只聚合状态和入口：

- 本机健康看板：CPU、内存、磁盘、网络、Windows 服务、打印服务和安全状态。
- 高频操作：一键电脑体检、电脑优化、办公修复、网络排障、打印机修复。
- 工具导航：按领域展示全部现有工具，并提供搜索和收藏。
- 运行动态：最近工具结果、失败重试入口、输出摘要与报告导出。
- 运维待办：活跃工单、告警、关联资产和最近处置单。
- 集成状态：可用与未安装的外部工具、版本与启动入口。

### 工具运行面板

工具页具有固定结构：

1. 工具名称、用途、权限与风险等级。
2. 参数区域与预检结果。
3. 执行控制：运行、停止、重试和受控修复确认。
4. 输出台：时间戳日志、结构化结果、成功/警告/失败状态。
5. 结论区域：发现、建议、验证步骤和回滚说明。
6. 结果动作：复制、导出、关联资产、创建工单、写入处置单。

现有 `appendOutput`、清空和复制行为在迁移期继续使用，公共运行器只负责补充状态、历史和结构化结果。

## 模块边界

### Tool Registry

每个工具在一个统一元数据表中登记：ID、名称、分类、描述、图标、风险等级、权限、输入配置、执行函数、输出类型和关联知识标签。既有工具的 ID 与调用方式保持兼容。

### Tool Runner 与 Output Console

Tool Runner 负责运行状态、重复执行拦截、取消、历史、审计和标准结果。Output Console 是统一输出界面，负责日志、复制、清空、导出和结果摘要。它不替代原工具实现，先作为兼容层承接现有输出函数。

### Desktop Operations

- 电脑体检：系统、硬件、磁盘、驱动、服务、更新、网络与安全检查。
- 电脑优化：临时文件、启动项、磁盘空间、网络缓存、电源方案和系统组件的可选检查与受控清理。
- Windows 修复：网络、更新、文件关联、共享、时间、服务和用户配置文件等诊断与修复。
- 打印与外设：保留现有打印工具并补充扫描仪、显示器、投影、蓝牙、串口和 USB 设备检查。
- 软件管理：软件盘点、运行库检测、常见组件状态、受控安装/卸载入口。

桌面运维覆盖矩阵必须包含：

- 硬件资产采集：品牌型号、序列号、CPU、内存、磁盘健康、电池、网卡、显示器、BIOS 与保修信息。
- Windows 健康诊断：蓝屏、事件日志、系统文件、驱动、更新、磁盘空间、启动项和服务。
- 常用系统修复：网络重置、DNS/DHCP、打印服务、Windows Update、文件关联、默认应用、共享、RDP 和时间同步。
- 软件管理：已装软件、版本、静默卸载、安装包仓库、Java/.NET/VC++ 等运行库检查。
- 用户与权限：本地账户、管理员组、密码策略、域状态、用户配置文件和组策略刷新。
- 数据迁移与备份：桌面、文档、浏览器书签、PST、打印机配置和网盘客户端配置的备份恢复。
- 外设专项：打印机、扫描仪、摄像头、U 盘、蓝牙、投影、显示器、多屏、串口、扫码枪、钱箱、电子秤和客显。
- 浏览器与协作：代理、证书、缓存、扩展、下载目录、企业站点兼容，以及 Outlook、企业微信、钉钉和 Teams。

### Office & WPS Repair

为 Word、Excel、PowerPoint、Outlook 和 WPS 提供共同的检测框架，以及按应用区分的修复卡。

检测包括安装与版本、进程、加载项、模板、缓存、文件关联、许可状态和事件日志。修复包括安全模式验证、禁用故障加载项、重建模板/缓存、重置文件关联、修复 Office 配置文件与 Outlook 数据文件。影响数据或设置的修复必须先给出备份及确认。

办公与业务环境还应检查证书、浏览器控件、加密狗、POS 运行环境、扫码枪、小票机和业务软件依赖，所有检查和修复结果进入同一输出台。

### Network, Security & Infrastructure

- 网络快照：IP、DNS、网关、路由、代理、Wi-Fi、端口、ARP 与连接状态一次采集并可导出。
- VPN/代理：客户端状态、路由冲突、证书、分流策略和 DNS 泄漏检查。
- 共享/NAS：SMB、凭据、映射盘、权限和网络发现排障。
- 安全基线：Defender、BitLocker、防火墙、补丁、弱口令风险、远程桌面暴露和 USB 管控状态。
- 应急采证：事件日志、系统信息、网络配置、进程、服务、截图和错误日志打包供二线分析。
- 服务器基础巡检：Windows/Linux 的 CPU、内存、磁盘、服务、端口、日志、时间和证书到期。
- 域控与 AD：域连通、DNS、GPO、账户锁定、组策略和 SYSVOL/NETLOGON 基础检查。
- 证书与域名：SSL 到期、证书链、DNS/WHOIS 和 HTTP 接口测试。
- 批量任务：批量 Ping、端口、软件、服务和磁盘检查，支持 CSV 导入导出。

### Three Field Shortcuts

- 一键现场采集：自动采集并归档到输出台、资产和工单。
- 桌面故障智能诊断：按无法上网、软件打不开、电脑卡、打印失败、蓝屏等现象串联检测工具。
- 交付验收清单：修复后自动验证网络、打印、Office、磁盘、更新和安全状态，生成可交付记录。

### Reports

报表中心输出巡检报告、维修报告、资产报告、优化前后对比和办公软件修复记录，统一引用工具输出、知识卡和审计事件。

### Knowledge Center

知识库分三层：

- 内置 SOP：本地离线的高频故障卡，按设备类别、品牌、型号、故障现象、错误码和操作步骤组织。
- 官方资料中心：厂商官网、驱动、固件、手册、下载和支持文章入口；仅记录经过白名单校验的官方 HTTPS 来源。
- 内部经验：工程师可录入的现场经验、附件、来源、适用版本、验证状态、复核时间和成功率。

一条知识卡应包含：标题、类别、品牌、型号/系列、系统或固件范围、症状/错误码、前置检查、步骤、风险、验证、回滚、官方来源、维护者、验证状态和更新时间。

首批恢复并扩展的品牌范围包括：华为、H3C、锐捷、TP-Link、Cisco、Fortinet、海康、大华、宇视、HP、Epson、Brother、Canon、Zebra、Dell、Lenovo、HPE、Synology、QNAP、Microsoft、WPS、APC/Schneider 与 Eaton。

知识库须支持全文搜索、筛选、错误码匹配、官方/内部来源标识、PDF/网页/OCR 导入、待验证审核，以及一键将知识卡附加到 AI 对话、工具输出和工单。

### External Integrations

已安装的 Wireshark、Nmap、HWiNFO、CrystalDiskInfo、SADP、RustDesk、AnyDesk、Net-SNMP 等工具独立展示。每项显示用途、版本、路径、来源、安装状态和启动入口。未安装工具提供官方获取入口，不捆绑或伪装第三方工具功能。

## 数据与安全

- 延续本地 `data/` 存储、环回监听、既有登录/RBAC 和审计模型。
- 诊断默认只读；修复操作通过权限检查、明确确认与审计记录执行。
- 不保存账户密码、密钥、SNMP 团体字串或其他敏感认证信息到知识库和导出报告。
- 修复输出记录执行前状态、执行动作、结果、验证与必要的回滚提示。
- 官方网页导入继续使用来源白名单和内容大小限制；资料的版权与许可信息保留在来源信息中。

## 命名与质量整改

- 所有浏览器标题、页面、文档、配置、启动脚本、导出报告和离线诊断页统一为“IT 运维百宝箱”。
- 清除当前前端、服务端和文档中出现的乱码/错误编码文本。
- 保持 API 兼容，测试工具注册、输出、知识库查询、权限、电脑优化和 Office 修复的关键路径。

## 交付顺序

### 第一阶段：保留与聚合

- 建立全量工具清单和兼容注册表。
- 重建首页、导航、搜索和统一运行面板。
- 修复项目命名与文字编码。

### 第二阶段：桌面核心

- 实现电脑健康检查、电脑优化和 Windows 高频修复。
- 实现 Office/WPS 检测与受控修复。
- 补齐软件、外设、用户配置和数据迁移能力。

### 第三阶段：知识与集成

- 恢复完整知识库页面、官方资料中心和品牌导航。
- 扩充内置 SOP，连接 AI、资产、工单和输出结果。
- 完善外部开源工具检测、状态和启动体验。

### 第四阶段：验证与交付

- 对每个原工具做可达性和输出台回归检查。
- 执行静态检查、构建、服务冒烟测试和浏览器桌面/移动端验证。
- 输出完整功能清单、首页规划、模块架构、迁移说明和测试结果。
